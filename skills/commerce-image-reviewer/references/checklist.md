# 商品检查标准 v1

| code | 检查依据与观察点 | 信息不足时 |
|---|---|---|
| PRODUCT_IDENTITY | 原始主体图：外形、结构、关键部件、Logo 所在部位；允许变换取自 spec | 缺主体参考、遮挡关键部位为 unknown |
| SKU_MATCH | 已确认 sku_id 与差异特征：颜色、规格标识、附件、款式；不能只凭文件名 | 两个 SKU 无可见区分依据为 unknown |
| PRODUCT_COLOR | 对照主体参考的颜色；考虑允许的光照变化，明显换色为 fail | 强色偏、反光或参考色不明确为 unknown |
| PACKAGE_TEXT | 原包装关键文字与最终营销文字；区分包装像素和后叠文字层 | 小字看不清为 unknown；未出现且明确不要求文字可 not_applicable |
| INCLUDED_ITEMS | 明确包含/不包含清单与数量；场景道具要区分 | 无清单或道具用途含混为 unknown |
| BRAND_LAYOUT | 品牌色、真实 Logo、营销文字层级、错字与拥挤；不判断法律授权 | 无品牌约束仍检查可读性；图中确无文字/Logo且无品牌要求可 not_applicable |
| COMPOSITION | spec 中裁切、留白、主体完整性、交付角色、比例视觉表现 | spec 缺失则不能假定达到指定要求；实际像素尺寸由程序检查 |
| COMPOSITE_QUALITY | 边缘白边、漂浮、接触阴影、透视、光向、透明/反射异常 | 无法分辨为 unknown，不因原像素保留就通过 |

商品身份、SKU、颜色、关键包装文字和包含物是关键商品检查。关键项不适用由程序验证；模型不能通过降低严重程度或提高美学分消除商品错误。

审核示例：瓶盖黑变白是可见差异，但透明瓶中因光照产生的轻微色变需要结合参考与 spec 判断；看不清“450ml”不能写成文字正确；背景中出现杯子需结合“道具/包含物”要求，不能直接断定赠送。

首版不用美学总分控制交付。品牌法律授权、平台审核通过、实际销售表现都不属于视觉模型可以确认的结果。

# 风格参考图素材清单规范

- 版本：`style-ref.1`
- 适用：M-V3「方案卡对比」的真实参考图
- 代码对应：`src/perception.mjs` 的 `STYLE_REF_MANIFEST_VERSION`、`styleReference()`

---

## 一、为什么需要这份规范

方案要求"用户通过比较图片判断自己更喜欢哪一种"。这个前提在 V2.0 里定为**真实参考图**，首期目标是实拍或已授权素材。

**2026-11-24 修订**：因为仓库内可用的合规实拍素材只有 4 张，缺口无法在当天补齐，经产品确认后**允许 AI 生成图进入清单，但必须满足三个条件**：

1. `source` 明确写「AI 生成示意」，`verified` 永久为 `false`；
2. 图片自带或叠加「示意图」标注，**不得裁掉或抹除生成工具的水印**；
3. 方案卡上显示「示意图」角标，不能让用户以为自己的商品做出来就是这样。

保留的硬边界：AI 图**永远不能**升为 `verified: true`，也**不能**用于对外宣传物料，只能用于让用户比较方向感。

原定的两条理由仍然成立，只是代价被接受：

1. **可比性**：真实摄影里的背景、光线、色彩关系是摄影决策的结果；AI 图也是摄影风格的结果，但细节（材质反射、商品结构）不可靠，所以只表达方向感，不表达"你的商品会这样"。
2. **素材成本**：用真实图需要拍摄或采购授权，AI 图是零成本替代，代价是可信度。所以标注必须做足。

## 二、目录与命名

```
frontend/assets/style-refs/
├── manifest.json
├── quality_premium/
│   ├── 1.jpg
│   └── 2.jpg
├── professional_trust/
│   └── ...
└── ...
```

- 一级目录是**感知方向 key**（只能取 `src/perception.mjs` 里 `PERCEPTION_KEYS` 的七个值之一，拼错会被 manifest 校验拒绝）。
- 文件名只用**序号** `{n}.jpg`，从 1 开始、方向内递增。
- **序号必须连续**：M-V3 方案卡按 `refIndex`（A 案=1、B 案=2）取该方向的第 n 张，中间缺号会让方案卡落到空态。每方向至少 2 张。
- **文件名必须是 ASCII**：中文命名在 URL 里需要额外编码，静态白名单与本地文件读取都会出错（M-V3 实测踩过）。品类写在 manifest 的 `category` 字段里，不进路径。
- 期望路径由 `styleReference()` 生成：`assets/style-refs/{perception}/{index}.jpg`；实际文件以 manifest 的 `file` 字段为准。

---

## 三、图片规格

| 项 | 要求 |
|---|---|
| 格式 | `.jpg`（首期统一，减少解码分支） |
| 比例 | 1:1 或 3:4（与主图/详情图一致） |
| 短边 | ≥ 800px |
| 体积 | 单张 ≤ 300KB（首屏三张同屏加载） |
| 内容 | 单一商品、主体清晰、无第三方平台水印、无促销角标 |
| AI 标识 | **AI 生成图的「AI生成」水印必须保留**，不得裁切、打码或抹除；另在方案卡上加「示意图」角标 |
| 文字 | 可以有少量文字，但不得有价格、店铺名、"限时"等促销信息 |

## 四、manifest.json 格式

```json
{
  "version": "style-ref.1",
  "updated_at": "2026-11-24",
  "items": [
    {
      "perception": "quality_premium",
      "category": "香氛",
      "file": "quality_premium/1.jpg",
      "source": "自有商品拍摄",
      "license": "自有版权，可用于产品展示",
      "verified": false,
      "added_at": "2026-11-24"
    }
  ]
}
```

字段约束：

| 字段 | 必填 | 约束 |
|---|---|---|
| `perception` | 是 | 必须是七个 key 之一 |
| `category` | 是 | 非空；`generic` 表示不限定品类 |
| `file` | 是 | 相对 `style-refs/` 的路径，且必须真实存在 |
| `source` | 是 | 素材来源说明（自有拍摄 / 已购授权 / 供应商提供） |
| `license` | 是 | 授权范围一句话说明 |
| `verified` | 是 | **是否已人工确认可商用**。默认 `false` |
| `added_at` | 是 | `YYYY-MM-DD` |

**`verified` 的语义**：`false` 表示"图片来源或授权未确认"，前端仍可展示但要带"参考图"标注；`true` 才表示已确认可商用。**不允许把 AI 生成图标成 `verified: true` 充当实拍参考。**

## 五、最低可验收集合

M-V3 视觉验收的门槛，不是最终规模：

| 约束 | 要求 | 当前状态（2026-11-24）|
|---|---|---|
| 每个方向 | ≥ 2 张 | 已达：七个方向各 2 张 |
| 覆盖品类 | ≥ 3 个不同品类 | 已达：护肤、香氛、家居、食品、日用、家电、运动、数码、茶器、陶瓷共 10 个 |
| 总张数 | ≥ 14 张 | 已达：14 张 |

**但这 14 张里 10 张是 AI 示意、4 张来源未核实。** 所以"张数达标"不等于"素材可用"：`verified` 仍全为 `false`，正式对外使用前需逐张替换为实拍或已授权素材。

## 六、现有素材盘点结论（2026-11-24 实测）

`frontend/assets/demo/` 共 14 张，逐张量过尺寸并逐张看过画面：

| 文件 | 尺寸 | 结论 |
|---|---|---|
| `sample-cream-hero.jpg` | 1200×1200 | 可用，已入 `quality_premium/1.jpg` |
| `sample-lamp-hero.jpg` | 1200×1200 | 可用，已入 `practical_value/1.jpg` |
| `diffuser-white.jpg` | 1024×952 | 可用，居中裁 1:1 后入 `quality_premium/2.jpg` |
| `diffuser-scene.jpg` | 1536×952 | 可用，居中裁 1:1 后入 `natural_comfort/1.jpg` |
| `sample-cream-scene / benefit / original.jpg` | 1200×1500 | **排除**：右下角带「AI生成」水印，按第三、八节不得入清单 |

## 七、缺图时的空态规则（硬性）

1. 方案卡在 `manifest` 里查不到对应条目，或文件缺失：**显示空态**，文案写"该方向参考图待补充"。
2. 空态时不得用 SVG 示意、渐变块、其他方向的图顶替。
3. 空态不影响用户选择该方向——参考图是辅助，不是前置条件。
4. 三个方向全部缺图时，方案卡退化为"名称 + 一句话描述 + 标签"的纯文字对比，并在面板底部说明"参考图待补充，当前仅按方向说明对比"。

## 八、版权与合规

1. **不得使用竞品商品图**作为参考图——即使是"只借风格"，画面里出现他人商品就是误导。
2. **不得使用来源不明的网图**。`source` 与 `license` 必须能说清。
3. **不得用 AI 生成图冒充实拍**。若确需 AI 图，`source` 必须写明"AI 生成示意"，且 `verified` 保持 `false`。
4. 人物出镜需有肖像授权；含可识别人脸的图一律不入清单。
5. 涉及第三方品牌 Logo 的图不入清单。

## 十、新增素材的落地步骤

`STATIC_FILES` 是显式白名单，新增任何文件都必须同步三处，否则线上 404：

1. 把图片放进 `frontend/assets/style-refs/{perception}/{n}.jpg`；
2. 在 `frontend/assets/style-refs/manifest.json` 追加一条（`file` 写相对 `style-refs/` 的路径）；
3. 在 `src/server.mjs` 的 `STATIC_FILES` 追加完整路径（`assets/style-refs/...`）。

`test/index.js` 会遍历 `STATIC_FILES` 逐个请求校验，漏加白名单或文件名写错都会在测试里暴露。

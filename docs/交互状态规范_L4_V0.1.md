# 千图百炼 · L4 交互状态规范 V0.1

日期：2026-11-23。状态：随批次 3（制作页 / 工作台交互与状态细化）落地。
上位文档：`outputs/千图百炼_UIUX大改方案_设计决策书_V0.1.md`（第 4 节 L4 行、第 9 节 V0.2 配色定稿）。
落点代码：`frontend/style.css`（L4 交互状态层）、`frontend/workbench.css`、`frontend/workbench.js`、`frontend/wizard.js`。

## 1. 全局硬规则

- **七态齐备**：每类交互组件必须定义 default / hover / active（按下）/ focus-visible / disabled / loading / selected 中适用的全部状态；纯展示组件可只声明不可用状态。
- **过渡时长**：统一使用 `--dur-fast:160ms` / `--dur:200ms` / `--dur-slow:280ms`，缓动 `--ease`；任何过渡不得超出 150–300ms 区间。
- **触达面积**：主要操作（primary/secondary 按钮、交付项、批量入口）≥44×44px；辅助文字按钮 ≥40px 高。
- **reduced-motion**：`@media (prefers-reduced-motion: reduce)` 全局把 animation/transition 压到近零；下划线滑动、tooltip 入场、弹窗入场自动退化为直接切换。
- **状态不裸靠颜色**：loading 用文字/转动图标，disabled 用 `cursor:not-allowed` + 文字说明，语义色始终配文字（沿用既有约定）。

## 2. 组件七态定义

### 2.1 标签页（.main-nav 顶栏导航 / .drawer-tabs 抽屉标签）

| 态 | 表现 |
|---|---|
| default | 未激活：淡紫文字 #9D8ECB（深紫顶栏）或 --muted（抽屉），无下划线 |
| hover | 文字变白/主色，无底色变化，200ms |
| active（按下） | 文字白色，下划线原点不动 |
| focus-visible | 3px 焦点环（既有全局规则） |
| disabled | 不可用时整项隐藏（导航不出现禁用项） |
| loading | 不适用 |
| selected | 白字 + 黄下划线 #FFD60A（抽屉为电紫下划线），`::after` 从中心 `scaleX(0→1)` 滑动 200ms；切换标签时旧线收起新线展开，形成滑动过渡 |

### 2.2 按钮（.primary / .secondary / .text-button / .icon-button）

| 态 | 表现 |
|---|---|
| default | 主：电紫底白字 + 柔和投影；次：白底描边；文字/图标：透明底 |
| hover | 主：#4A08A8；次/文字：浅紫底 #F3E8FF + 描边加深；图标：深紫顶栏内白 16% 底 |
| active | 主按钮 `translateY(1px)` + 投影收窄（160ms） |
| focus-visible | 3px 电紫焦点环，offset 2px |
| disabled | 透明度 .55 + `cursor:not-allowed` + 投影取消 |
| loading | 追加 `.is-loading`：原文字变透明，中心出现旋转 spinner（白/紫按底色），`pointer-events:none`；文案由 JS 同步为「正在…」 |
| selected | 导航/标签类按钮用 selected 态；普通按钮无 selected 语义 |

### 2.3 输入框（input / select / textarea）

| 态 | 表现 |
|---|---|
| default | 白底 + #E2E8F0 描边 |
| hover | 描边加深为淡紫 #C9BCEF（未聚焦时） |
| active | 不适用（键盘输入无按压态） |
| focus-visible / focus | 电紫描边 + `--ring` 柔光环（既有） |
| disabled | 浅紫底 + `cursor:not-allowed` + 弱化文字 |
| loading | 不适用（提交类用按钮 loading 表达） |
| selected | 文本选中色继承系统；表格行/卡片类可选中容器见 2.5 |

### 2.4 状态签（.wb-status / .wb-chip / .status-pill / .v2-pill）

| 态 | 表现 |
|---|---|
| default | 语义底色 + 同系深色文字（绿/琥珀/红/紫），min-height 24px |
| hover | 若带 `data-reason`：轻微加深底色并弹出成因 tooltip（见 3.2） |
| active / focus-visible | 可点击的状态签（如额度签）沿用按钮焦点环 |
| disabled | 不适用 |
| loading | 生成中用 `running` 紫 + 「…」图标，不虚构进度 |
| selected | 不适用（状态签无选中语义） |

### 2.5 卡片与列表项（.wb-deliverable / .wiz-template-card / .wiz-fact-card / .project-card / .asset-card / .wb-edit-thumb）

| 态 | 表现 |
|---|---|
| default | 白底 + 1px 描边 |
| hover | 描边转电紫 + 投影上浮（180ms） |
| active（按下） | 背景加深一档（#F0ECF7） |
| focus-visible | 2–3px 焦点环（既有各组件规则保留） |
| disabled | 透明度弱化 + 不可点（如未生成完成的交付项仍可查看但不可修改） |
| loading | 内容区显示 `.loading-line` 骨架（既有） |
| selected / active | 电紫描边 + 浅紫底（.selected / .active），`aria-pressed` 同步 |

### 2.6 弹窗（dialog / .real-dialog / 抽屉 .drawer）

| 态 | 表现 |
|---|---|
| default | 白底、10px 圆角、深紫 45% 半透明 backdrop |
| hover / selected | 不适用 |
| active | 不适用 |
| focus-visible | 打开时焦点落到弹窗内首个可交互元素；关闭按钮有焦点环 |
| disabled | 提交中禁用按钮（沿用 disabled 态） |
| loading | 内容区 `.real-hint` / `.loading-block` 骨架 |
| selected | 不适用；打开动画 `translateY(10px)+scale(.98)→1`（280ms），reduced-motion 直切 |

## 3. 落点映射（批次 3 已实现）

- 3.1 下划线滑动标签页：`style.css` L4 层 `.nav-item::after` / `.drawer-tabs button::after`。
- 3.2 状态签成因 tooltip：带 `data-reason` 的元素悬停/聚焦弹出自绘 tooltip（`[data-reason]:hover::after`），由 `workbench.js` 在渲染状态签（#wb-status-pill）与检查行（.wb-qa-row）时写入成因文字；不依赖 title 原生提示，保证与产品文案一致。交付项（.wb-deliverable）位于 `overflow:auto` 的左侧清单内，自绘 tooltip 会被滚动容器裁切，故改用原生 `title` 承载同一成因文字（内容来源相同）。
- 3.3 loading 按钮：`wizard.js` 生成按钮（「正在锁定配置…」）与 spec 弹窗冻结按钮追加 `.is-loading`。
- 3.4 44px 触达：`.primary/.secondary` min-height 44px；`.wb-deliverable` min-height 44px；`.text-button` 40px。
- 3.5 reduced-motion：全局压缩动画时长（style.css 末段）。

## 4. 边界与声明

- 本规范只覆盖交互状态与微动效，不改变既有实现契约（readiness 闸口、额度账本、SSE 事件契约等）。
- tooltip 成因文字来自前端渲染时的真实数据映射，缺数据时显示通用说明，不虚构检查结论。
- 「提升转化/效率」类收益在商家内测前不得宣称。

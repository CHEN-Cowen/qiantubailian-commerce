体验说明

先试流程，再判断价值。

这是独立 HTML 演示，全部操作在浏览器中完成。不会创建正式账户、保存到业务后台、发起支付或调用付费模型。
这个演示能做什么？

浏览产品介绍与模板，上传本地图片，输入商品事实，选择配色，生成并下载三张带演示标识的排版图片。无需注册。

我上传的图片会被保存吗？

图片仅在当前浏览器内存中用于预览和画布排版，本演示不会将它上传到服务器。刷新页面即清除。下载文件由你保管。

它和正式产品的区别是什么？

正式产品的账户、任务队列、模型生成、商品主体保护、事实版本、质量复核与交付记录需要后端服务。本页仅演示界面和排版流程，不提供上述能力的验收保证。

付费如何呈现？

正式产品计划采用先体验、后购买额度的方式，并在生产前显示用量、价格和扣费规则。这个演示不设付费门槛、不展示可购买订单、不接收个人收款。

能把演示发给别人吗？

可以分享在线链接，也可以下载下面的单文件 HTML，发给对方用浏览器打开。离线文件同样支持上传、排版和下载。

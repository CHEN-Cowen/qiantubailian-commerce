## 模块 01：绿色视觉系统与页面骨架

### 实际实现

1. 全站调色板从橙色系切换为低饱和绿色系（对齐 `reference/green-demo`）：主色 `#365F49`、深绿 `#2C4C3B`、强调 `#6E8F79`、背景 `#F7F8F5`、浅绿面 `#EDF2EC`、分割线 `#DFE5DC`、主文字 `#263A32`、次文字 `#6D786F`。覆盖 `style.css`、`workbench.css`、`m03/m04/m05/pricing.css`、`index.html` 内联色值，以及 `auth.js`、`workbench.js` 内嵌样式；`rgba` 阴影同步换色。
2. `style.css` 末尾新增设计系统层：`:root` 语义变量（brand/warn/danger/surface/间距/圆角/焦点环）、状态反馈组件（`.state-note` warn/danger/ok、加载 shimmer、空态）、主按钮阴影与禁用态、输入焦点样式、键盘焦点环。
3. 顶栏改为绿色演示同款骨架：导航文案「首页 / 我的商品 / 我的作品 / 品牌与模板」，额度常驻胶囊 `#topbar-credits`（与额度弹窗同源，`real-data.js` 写入真实账本余额，不写死数字），「演示数据」改「演示边界」。
4. 工作台布局去三栏：`workbench.css` 改为「左侧 328px 设置 + 右侧预览」，质检/复核/交付信息移到预览下方整宽排列（`.wb-right` 两列自适应）；≤1100px 收窄，≤820px 单列（设置→预览→信息），顶栏与画布操作移动端换行不溢出。
5. 首页标题改为价值表述（"把新品，做成一套能上架的视觉资产"），副标题说明费用前置；项目/作品/品牌页标题与说明同步改为用户语言。
6. 移动端与可访问性：≤960px 顶栏换行、指标两列、网格单列；≤560px 卡片单列；`prefers-reduced-motion` 关闭动画；`forced-colors` 兜底；按钮/输入 `focus-visible` 焦点环。
7. 状态不改语义色：失败红 `#B91C1C`、复核琥珀 `#B45309` 保留，检查未通过不渲染绿色成功。

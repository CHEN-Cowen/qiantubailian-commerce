# 使用说明
把整个文件夹交给有代码编辑、终端、浏览器测试和Git能力的开发软件，并粘贴03-总执行提示词-直接复制.md全文。

- 01：完整开发范围、目标交互、代码入口、数据约束、M00–M08实施步骤与完成标准。
- 02：自动连续开发、自检修复、Git提交推送、远端验证、异常恢复和最终端到端流程。
- 03：直接复制给开发软件的总提示词。
- 04：竞品一手资料参考，帮助理解方案，不代替需求。

执行环境需要：仓库访问与推送权限、符合仓库要求的Node、可用浏览器工具。真实模型验收还需要对应凭据和明确预算；不必把凭据发给聊天，使用执行环境安全配置。
默认推送专用开发分支，不自动合并主分支或部署生产。用户无需逐模块批准。后续若明确指定目标分支，则执行者核对保护与部署影响后使用该分支。
本交接包编写期间未执行产品开发、产品验收或Git推送。文档检查不等于产品已通过检查。

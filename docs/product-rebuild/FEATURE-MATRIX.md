# 功能入口事实矩阵（M00）

状态定义：
- **真实**：代码已连到服务端/本地真实行为，最终仍需运行验收。
- **示例**：明确标注为演示，不进入正式数据。
- **缺失**：需求要求但当前无实现或入口。
- **待修**：入口存在，但存在误导、失败、阻塞或未闭环。
- **待验**：代码已接入，尚未在本轮浏览器/接口验收中确认。

## 已确认需要重构的五处

1. 引导文案：不解释“商品图/商品信息/制作方案/报价/生成/交付”的关系。
2. 商品信息：技术表格与“需要确认”缺少可理解的问题和示例。
3. 卖点填写：无入口、无法生成有依据的文案候选。
4. 最后一步任务过多：方案、背景、品牌、交付、高级设置、报价混在一起。
5. 提交后结果追踪：无同上下文状态、失败原因与下一步。

## 外部条件限制

- 真实供应商、真实支付、生产数据不在本轮授权范围；未配置时不伪装为已上线。
- 站点部署与线上验收依赖外部环境，本轮只保证本地/仓库结果。

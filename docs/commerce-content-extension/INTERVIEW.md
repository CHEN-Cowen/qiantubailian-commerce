# 千图百炼：商家访谈提纲与记录模板

版本：1.0｜日期：2026-10-28｜建议时长：35–40 分钟。

## 一、访谈目的

查明三个任务是否真实、频繁、麻烦且适合千图百炼解决：商品变化后的图片更新、SKU图片对应核对、顾客疑问的信息补充。

不是让对方评价我们的想法。前半程不展示产品、不介绍拟做功能，不先把“漏改”“串图”“反复被问”塞给对方。无痛点和满意现状同样是有效结果。

公开研究已发现的重点偏差：图库不切换可能是主题问题；错变体可能是发货问题；尺寸可能是运费问题；问得多可能用短文字或FAQ就足够。访谈要核对这些边界，而不是寻找支持我们方案的说法。

## 二、招募与安排

首轮建议 8 位：尽量同一细分类目，同时覆盖单/多规格、单/多渠道、自己做图/外包、有/无近期维护任务。至少 2 位来自“没有近期问题或现有工具满意”的对照组。

先接触后筛选并记录总人数，不直接只招“被图片维护困扰的人”。受访者最好是实际处理商品图的店主、运营或客服，需知道谁掌握预算。

筛选问题：

1. 主要卖什么，在哪些渠道销售？
2. 谁负责商品资料、图片、客服和上架？
3. 大约有多少商品、多少规格？问区间即可，不要求财务隐私。
4. 最近一次上新或修改商品页面是什么时候？
5. 你能否描述一次近期操作？是否方便自愿展示脱敏材料？不同意展示也可以参加。

邀请话术（由用户自行发送，本文件不代表已代发）：

> 我在了解小商家平时怎样制作和维护商品图片，想请你聊一次最近的实际操作，大约35分钟。不是推销，不需要提供账号密码、顾客信息或销售额。没有遇到问题也很有帮助；如方便，可以展示一份去除敏感信息的图片或修改记录。不想展示或不愿录音都不影响交流。

## 三、开场：2–3分钟

> 今天主要想了解你实际怎样做商品页面和图片，没有标准答案，也不用照顾我的想法。我们先聊最近做过的事情。材料可以不展示，敏感信息可以遮住。时间约35分钟，现在方便吗？

若需要录音，单独询问是否同意；未同意则只记匿名笔记。说明录音用途、存放和预计删除时间，不笼统索取客服或订单资料。

## 四、热身与任务选择：5分钟

1. 请讲讲你这周和商品页面有关的工作。
2. 最近一次上传或修改商品图，你从什么地方开始，最后怎样算完成？
3. 谁参与，使用什么工具，文件通常放在哪里？
4. 最近哪些工作最占时间？请先让商家自己排序。

从对方刚提到的真实任务中选择一条先深挖。以下三个分支不是都要机械问完：优先深入有具体事件的一支，其余用短问判断是否存在。

## 五、分支A：商品变化后的更新，8–10分钟

主问题：**请带我回到最近一次商品资料或实物发生变化的时候，当时发生了什么？**

中性追问：

- 是谁通知变化，原信息和新信息是什么？
- 当时需要处理哪些文件或页面，你怎样找出它们？
- 按实际顺序讲一遍：先做什么，接着做什么，最后怎么检查？
- 若方便，能否展示一份脱敏的旧图与新图，或操作记录？
- 哪些动作由你做、哪些交给别人，实际操作和等待分别多久？
- 处理完后发生过遗漏或其他问题吗？若没有，是什么办法避免了它？
- 新旧包装/库存是否同时存在？若有，页面如何表达？
- 最近30天有几次类似任务？若没有，最近90天呢？数量来自记录还是估计？
- 以前试过什么工具或外包，最后为什么继续/停止？实际花费大约多少？

边界追问：如果图已修改但平台没显示，具体卡在图片制作、上传审核、前台展示还是实物库存？不要将平台/库存问题记为“更新助手必能解决”。

不问：“如果有一键更新你会买吗？”改问：“你上一次为这件事付过什么成本？最后选择怎样解决？”

## 六、分支B：SKU与图片对应，8–10分钟

主问题：**请拿最近一个有多个规格的商品，讲讲图片怎样对应到每个规格。**

- 先有哪些规格，又是谁决定每张图对应哪个？
- 一张图片是否会被多个规格共用？什么情况下可以共用？
- 文件怎样命名、分组、交给上架人员？
- 最近一次检查对应关系是什么时候，怎么检查？
- 如果出现过不一致，请讲最近一次；如果没有，现有方法哪里足够好？
- 哪个阶段出现：原照片/设计图错、文件命名错、后台绑定错、前台不切图、订单选择错、仓库拿错？
- 怎样发现、谁来修、实际修了几次？有没有可展示的脱敏证据？
- 套装包含物、赠品和拍摄道具通常怎样说明？顾客有没有具体误解？
- 最近30/90天多少次？每次实际操作多久？后果是确认过的还是推测？
- 现在有没有ERP、图库插件、表格或人工复核？是否付费？为什么不直接继续使用？

必须记录错误所在层级。若只是主题不切图或错发货，不推导“需要生图防串功能”。

## 七、分支C：重复询问与信息补充，8–10分钟

主问题：**最近一周顾客在购买前问过哪些问题？请选一个你记得最清楚的例子。**

- 顾客原来怎么问，你当时怎么回复？有匿名文字片段更好。
- 答案是固定商品信息，还是依赖对方条件？例如尺寸值与“能否放进他的柜子”分别记录。
- 当时商品页哪里已经写过或画过？在手机端什么位置？
- 同一问题最近7天多少次，大约对应多少次咨询？没有记录就写未知，不催估数字。
- 回一次用了多久？是否已有快捷回复、FAQ、尺寸表或客服机器人？
- 上一次你为此改过页面吗？具体改了什么，为什么选图片/文字/位置变化？
- 后来怎么判断有效？有没有同期流量、订单、投放或促销变化？
- 尝试过的方法里，有没有很简单就够用的？有什么不需要再做？
- 若缺少尺寸/包含物资料，现在从哪里查、谁确认？

把商品尺寸、包装内容等与物流、库存、支付、退换政策分开。后者未必适合用商品图解决。

## 八、当前优先级与真实投入：3分钟

1. 刚才这些事情与你这周其他工作相比，最值得先解决的是哪件？为什么？
2. 已经投入了哪些时间、人工、工具或外包成本？一次性和持续付费分开。
3. 你最近找过替代办法吗？搜了什么、比较过什么、为什么没有换？
4. 最后由谁决定换工具？换工具还需要录入资料、培训或其他步骤吗？

优先记录已发生的支出与行为，不把“将来愿意花多少钱”的口头答案当支付验证。询问成本用区间，未知留空，不从公开帖子填入。

## 九、结束与可选人工试做：3–5分钟

先复述：“我理解你上次主要卡在……，现有处理是……，还有哪些理解不对？”

然后问：还有什么重要的没问到？是否有实际处理过这件事的人适合继续聊？是否愿意自己转达邀请？未经授权不直接联系推荐的人。

如对方有现实待办，再提供一个可选择的行动：

> 如果你近期正好有类似任务，我们可以用一份你愿意提供的脱敏资料试做一次清单、核对或说明图。先约定范围和完成标准，看看是否比现在的方法省事；没有合适任务就不勉强。

记录是否实际给资料、是否约定任务、是否采用、是否再次使用。口头夸奖、点击链接和同意加好友不能算采用。人工免费试做也不能证明愿意付费；具备收款条件后再单独验证。

## 十、现场追问工具与避免诱导

可用：“最近一次是什么时候？”“接下来发生什么？”“能举一个具体例子吗？”“这个数字是记录还是估计？”“有没有相反情况？”

避免：“是不是经常漏改？”“有AI是不是方便很多？”“你肯定需要自动核对吧？”“这个功能你会付19元吗？”

替换为：“上次如何确保改完？”“目前最省事的方法是什么？”“如果什么都不换，会怎样？”

尽量让商家说话，追问完整事件而非填满问卷。不否定对方的现有工具，也不因无痛点就反复诱导。

## 十一、单场记录模板

### 基础

- 受访编号、日期、时长、招募来源：
- 类目、平台、角色、商品/SKU区间：
- 谁处理图片、谁接客服、谁决定预算：
- 录音许可、材料使用范围、是否脱敏：
- 本次分支及为什么选择：

### 每个具体事件单独一行/一段

- 事件时间、触发原因、当时目标：
- 适用商品/SKU/渠道范围：
- 操作步骤、人员、工具与交接：
- 实际卡点与错误所在层级：
- 原话（自愿记录）及证据编号：
- 事实/商家估计/研究者推断，分别标记：
- 操作时间、等待时间、金额、返工次数；未知留空：
- 频次与观察窗口、记录还是回忆：
- 已采取办法、为什么有效/不足、现有替代品：
- 已知后果、推测后果，分别记录：
- 无痛点/反例：

### 行动与判断

- 是否有近期真实待办：
- 是否实际提供资料与授权范围：
- 约定试做内容与完成标准：
- 是否采用/二次使用（待后续观察）：
- 预算/决策行为证据：
- 尚未确认的问题：
- 下一步、负责人和时间（由双方实际约定）：

## 十二、跨访谈汇总和决策

三个功能分别统计，不合并“任意一个痛点”来宣布三者都有需求。记录无问题商家和不愿换工具原因。

将证据按以下状态标记，不假装是精确科学评分：

- 只有看法：没有近期事件。
- 具体回忆：说得清经过，但无记录。
- 有材料：脱敏图、修改记录或匿名问题等能对应事件。
- 有行动：投入过时间/费用、实际提交试做、采用结果。
- 有复用：再次有任务并主动回来。付费另记，免费复用不等于付费。

建议8场完成后，按《公开案例检索报告》的小试点门槛决定继续。若同方向至少3位有近期具体案例、其中2位实际采用试做，才值得进一步小规模验证；这不是对目标市场需求比例的估计。

没有实测分母不写“客服减少X%”；没有真实用户就不填写虚构引语、反馈与成绩。

# 千图百炼 · 部署手册

> 版本：0.21.0 | 适用模块：R00-R11

## 1. 前置条件

| 项目 | 要求 |
| --- | --- |
| Node.js | >= 22.22.2 < 23 |
| 操作系统 | Windows / macOS / Linux |
| 磁盘 | >= 500MB（数据目录随使用增长） |
| 网络 | 仅 loopback 监听，不暴露公网 |
| 第三方依赖 | 无（纯 Node.js 标准库） |

## 2. 启动

```bash
# 克隆仓库
git clone https://github.com/CHEN-Cowen/qiantubailian-commerce.git
cd qiantubailian-commerce
git checkout feat/commerce-commercialization

# 启动（默认 127.0.0.1:3000）
npm start

# 自定义端口和数据目录
QTB_PORT=8080 QTB_DATA_DIR=/data/qtb npm start
```

### 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `QTB_PORT` | `3000` | 监听端口 |
| `QTB_DATA_DIR` | `./runtime/` | 数据目录（JSON + 文件体） |
| `QTB_PAYMENT_PROVIDER` | 未配置 | 支付 Provider：`mock` 或 `wechat_native` |
| `QTB_WX_MCHID` | - | 微信商户号（wechat_native 必填） |
| `QTB_WX_APPID` | - | 微信 AppID |
| `QTB_WX_APIV3_KEY` | - | 微信 APIv3 密钥 |
| `QTB_WX_PRIVATE_KEY` | - | 微信商户私钥（PEM） |
| `QTB_WX_PLATFORM_CERT` | - | 微信平台证书（PEM） |
| `QTB_WX_NOTIFY_URL` | - | 微信支付回调地址 |
| `NODE_ENV` | - | `production` 时关闭演示身份 |

## 3. 单实例限制

**当前架构为单进程单实例**。数据存储为 JSON 文件 + 文件体（blob），不支持多实例并发写入。

| 限制 | 说明 |
| --- | --- |
| 存储 | 单进程 `store.mutate` 串行化写入，多实例会导致数据不一致 |
| 定时任务 | 内置 tick 调度器，多实例会重复执行 |
| SSE 事件流 | 内存中的事件队列，多实例无法共享 |
| 备份 | 租户级快照导出，恢复时替换该租户数据 |

**生产部署建议**：
- 单实例部署，前置反向代理（nginx/caddy）做 TLS 终止
- 数据目录挂载持久卷
- 定期执行备份 API 或文件级备份
- 多实例需要替换存储层为数据库（PostgreSQL/SQLite WAL）

## 4. 健康检查

```bash
# 存活探针
curl http://127.0.0.1:3000/healthz

# 就绪检查（验证静态资源完整）
curl http://127.0.0.1:3000/readyz
```

## 5. 指标

```bash
# 聚合指标（需认证，需 metrics:read 权限）
curl -H 'x-tenant-id: tenant_demo' -H 'x-actor-id: operator' http://127.0.0.1:3000/api/metrics
```

指标包含：
- **HTTP**：请求总数、按状态码分布、错误率
- **工作量**：项目数、任务数、批量数、导出数
- **商业化**：首张可用图耗时、采用率、失败率、每张成本、付款转化
- **额度**：可用额度、预留额度
- **存储**：各表行数

## 6. 备份与恢复

```bash
# 创建备份
curl -X POST -H 'x-tenant-id: tenant_demo' -H 'x-actor-id: operator' \
  http://127.0.0.1:3000/api/backups

# 查看备份列表
curl -H 'x-tenant-id: tenant_demo' -H 'x-actor-id: operator' \
  http://127.0.0.1:3000/api/backups

# 恢复备份
curl -X POST -H 'x-tenant-id: tenant_demo' -H 'x-actor-id: operator' \
  http://127.0.0.1:3000/api/backups/{backup_id}/restore
```

备份包含：项目、资产、事实版本、规格、任务、额度账本、批量、导出记录、订单等全部租户数据。

## 8. 无密钥演示

不配置任何外部密钥时，系统以演示模式运行：
- 使用模拟 Provider 生成图片（不调用真实 AI 服务）
- 支付能力降级为演示模式（可手动结算）
- 所有功能可用，但生成的图片为模拟数据

配置真实 Provider 后自动切换为真实模式。缺配置时启动即抛错，不悄悄降级。

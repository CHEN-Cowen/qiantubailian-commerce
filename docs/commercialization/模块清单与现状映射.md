# 千图百炼 · R00—R12 模块清单与现状映射

本文件把本轮商业化指令的 13 个模块与仓库既有能力逐项映射，明确“已实现 / 仍缺 / 验收条件”。
既有代码来自 M01—M12 与 UI01—UI04（基线 `b623b84`）。

## R00 现状核对与执行计划

- 已实现：M01—M12 全链路代码、129 项自动化测试、语法检查、SSE、备份恢复。
- 仍缺：商业化模块的进度台账、外部依赖清单、测试数据隔离说明（本轮补齐）。
- 验收：基线检查可执行并记录；后续模块都有对应验收项；分支与远端明确。

## R01 真实身份、租户与角色权限

- 已实现：`m11.mjs` 的角色矩阵（owner/editor/reviewer/viewer）、成员表、最后 owner 保护。
- 仍缺：
  - 真实登录与会话（当前靠 `x-tenant-id` / `x-actor-id` 自报）；
  - 生产默认身份放行（缺省回落到 `tenant_demo` / `demo_operator`）；
  - 项目、素材、事实、spec、报价、任务、取消、预算追加、质检复核、版本、导出、批量、配方、反馈、计费、备份的统一权限闸口；
  - CSRF、Cookie、安全头、登录限流、账户恢复。
- 验收：未登录拒绝；伪造身份头不能越权；viewer 不可创建/改事实/生成；非成员不可读；跨租户资源与下载不可访问；最后 owner 保护保留。

## R02 生成状态、数量、超时与供应商成本安全

- 已实现：unknown 状态不改变账面、迟到结果只审计、`recover()` 恢复中断任务、attempt 级幂等键、QA 报告。
- 仍缺：
  - 本地超时被当作可重试失败，会发起新的供应商请求；
  - 未先查询/对账原供应商调用；
  - `count > 1` 未展开为可独立追踪的图片项；
  - 并发限制仅按 run 内 attempt 计，没有供应商级/租户级限额；
  - 供应商成本未覆盖失败、修订与退款。
- 验收：持续 unknown 不产生重复外部工作；取消后迟到结果不复活；重启有恢复路径；模板要求 1 封面 + 2 内页必须有 3 个产物；成本与用户额度分开可追踪。

## R03 成品额度、预算与账本

- 已实现：只增台账、唯一操作键幂等、预留/结算/释放/退款、余额不得为负、并发原子预留。
- 仍缺：
  - 体验额度、月度包、一次性包、有效期、到期优先消耗、到期处理；
  - 用户成品额度与供应商成本分账；
  - 退款冻结与并发生成；
  - 套餐权益快照。
- 验收：余额不足不调用模型；并发不超用；重复请求不重复预留/结算/退款；重启前后余额一致；同版本重复下载不收费。

## R04 真实图像执行、商品保护、文字与质量检查

- 已实现：Provider 接口与能力校验、确定性模拟 Provider、Seedream Adapter、掩码/主体合成、QA 检查、事实与文字核对框架。
- 仍缺：
  - 从冻结事实、素材职责、品牌、构图、平台尺寸、文字布局编译请求指令；
  - 修订动作转成 Provider 支持的编辑参数；
  - JPEG/PNG/WebP 实际处理链路验证；
  - OCR/文字核对可配置能力；
  - 真实 Provider 效果验收（需密钥与费用授权）。
- 验收：改事实/风格/修订目标会产生请求变化；常见格式可处理；硬错误阻断；未知可辨识；修订不覆盖已通过项。

## R05 统一真实商品制作工作台与任务恢复

- 已实现：后端 run 查询、SSE 事件流、导出与部分导出、版本回退。
- 仍缺：
  - 真实项目统一工作台（上传→核对→选效果→报价→生成→修改→下载）；
  - 前端按 run_id 恢复任务、断线重连与轮询兜底；
  - 逐张状态、局部修改、人工确认、完整/部分导出 UI；
  - 报价字段契约复测。
- 验收：真实用户能拿到图片/ZIP；部分包明确缺项；刷新/重登后任务仍在；看历史结果不自动扣费。

## R06 首页、信息架构、品牌复用与界面完善

- 仍缺：真实账户数据组织、首次/回访分流、品牌配方复用入口、可访问性与窄屏修复。
- 验收：数据与空状态真实；示例可返回真实制作；配方可用于第二个商品；桌面与 375px 可操作。

## R07 价格页、付费入口与使用规则

- 已实现：`/api/plans` 套餐清单、支付能力闸口、内部演示订单。
- 仍缺：价格页、用量/订单页、生成前清单与最高消耗确认、追加购买入口、额度有效期与退款规则展示。

## R08 微信 Native 支付、到账与对账

- 仍缺：微信 Native 下单、APIv3 验签/解密、主动查单、关单、通知幂等、对账（需商户资质与密钥）。

## R09 退款、追加包与售后

- 已实现：退款闸口与内部演示阻断。
- 仍缺：订单退款申请、退款单状态机、权益冻结/解冻、部分退款规则、售后异常入口。

## R10 批量与平台输出收口

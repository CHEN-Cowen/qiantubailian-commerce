## 关键断言（test/r01.js）

| 场景 | 断言 |
| --- | --- |
| 生产口径匿名访问 | `/api/projects`、`/api/credits`、`/api/quotes`、`/api/runs`、`/api/exports`、`/api/plans` 均 401 `UNAUTHENTICATED` |
| 伪造身份头 | 无 Cookie 时携带 `x-tenant-id` / `x-actor-id` 仍 401 |
| 注册 | 201 + `HttpOnly; SameSite=Lax` Cookie；`data.json` 中不含会话令牌明文 |
| 会话身份 | `/api/tenant` 的 `actor_id` 等于账户 ID，`x-actor-id` 被忽略；`mode=session` |
| CSRF | 缺失 403 `CSRF_REQUIRED`；错误令牌 403 `CSRF_INVALID`；正确令牌 201 |
| 租户越权 | 会话使用未加入的 `tenant_other` → 403 `TENANT_FORBIDDEN` |
| 非成员 | 知道项目 ID 也读不到（403 `TENANT_FORBIDDEN`），自己的列表为空 |
| viewer | 可读项目；创建项目/写事实/建报价/建任务/管成员均 403 |
| 最后 owner | 删除自己 409 `MEMBER_LAST_OWNER` |
| 登录限流 | 连续 5 次错误密码后，正确密码也 429 `LOGIN_LOCKED` |
| 跨站写 | `Origin: http://evil.example` → 403 `CROSS_ORIGIN_DENIED` |
| 退出登录 | 200，旧 Cookie 再访问 401 `SESSION_INVALID` |
| 配置隔离 | 生产 `QTB_DEMO_MODE=1` 拒绝启动；生产 Cookie 自动 `Secure` |
| 账户恢复 | 未配置邮件 → 503 `EMAIL_SERVICE_NOT_CONFIGURED` |

## 浏览器证据

在隔离临时数据目录、`demoMode:false`、端口 3105 的真实浏览器操作：

1. 首屏出现全屏登录对话框（标题「登录你的商品视觉工作台」），无 500 文本。
2. 切换注册后出现「昵称」「工作区名称」，按钮变为「注册并开始」。
3. 注册 `browser.r01@example.com` 后页面重载，对话框消失。
4. 顶栏头像 `title` 为「小林 · 小林的手作」，与会话一致。
5. 进入「商品项目」，真实列表为空状态「尚未创建项目…」，不是认证错误。
6. 控制台无错误；网络无 5xx。

## 遗留与外部依赖

- 账户找回依赖邮件服务（EXT-12），当前显式 503，不假装可用。
- 未接入短信登录，首期不依赖。
- 生产 Cookie 需 HTTPS（EXT-05）；当前服务仅允许 loopback 宿主。
- 多租户切换只支持同一账户已加入的工作区，邀请流程沿用 M11 成员接口。

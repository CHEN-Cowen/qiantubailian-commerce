## 1. 范围与实现

| 要求 | 实现 |
| --- | --- |
| 配置/修订真正进入供应商请求 | `src/execution.mjs` 编译执行指令：背景、光线、构图、机位、平台、已确认事实、包装关键文字、品牌色/字体、禁用表达、不可改变项、缺失信息全部写入 `prompt`；`execution.content_hash` 进入请求并参与 `request_hash` |
| 冻结输入 | run 创建时按 `spec.product_truth.version` 与 `spec.brand_kit.id/version` 取冻结事实与品牌版本，运行期间不随草稿变化 |
| 修订动作与保留项 | `compileRevisionInstruction` 把动作码、参数与"必须保留的已通过检查项"编译成文本与哈希，写入修订请求；与 `M08.planRevision` 的 `preserve_checks` 对接 |
| 常见格式输入 | PNG 走 `border_color_keying` / `alpha_channel` 自动推导；JPEG/WebP 需卖家确认归一化矩形（`manual_box`），无去背图时 `has_cutout=false`，`checkSubjectProtection` 返回 `UNSUPPORTED_CAPABILITY`，不假称可本地合成 |
| 掩码预览与调整 | `GET/POST …/assets/:id/mask-preview` 返回预览并带 `X-Mask-Method`/`X-Mask-Coverage`/`X-Mask-Has-Cutout`；`PUT/PATCH …/subject-box` 保存归一化矩形，只写元数据不改写原图像素 |
| OCR 可配置 | `src/ocr.mjs` 由 `QTB_OCR_ENDPOINT/API_KEY/MODEL/TIMEOUT_MS` 判定；未配置恒返回 `unknown`，配置后 `acceptance='contract_only'`；HTTP 失败不返回空数组冒充"图中无文字" |
| 事实提取需人工确认 | `extractionCandidates` 产出全部 `confirmed:false`，低置信或无置信度标 `needs_evidence`；未确认候选不进入生成请求 |
| 文字与 Logo 走可编辑排版层 | `buildOverlaySvg` 生成含 `<image>` 底图与带 `data-fact`/`data-source` 的 `<text>` 图层，随导出写入 `overlays/<id>.svg`；`text_policy.render_text_by_provider=false` |
| 关键文字核对 | `checkCriticalText` 对成品做包含式核对（去空格小写），不符即硬失败；OCR 不可用时保持 `unknown`（`src/m07.mjs` 检查项 `OCR_CRITICAL_TEXT`） |

## 2. 产品规则落地

1. 商品真实性优先：未确认事实、未确认 OCR 候选一律不进入指令；缺失项在指令中显式写 `FACT_NOT_CONFIRMED`，禁止模型补写。
2. 文字不交给模型绘制：`render_text_by_provider=false`，营销文字/规格/Logo 走 SVG 排版层，包装文字来自已确认事实与关键文字。
3. 修订针对具体错误：修订指令只含失败动作与参数，并显式列出必须保留的已通过项。
4. 能力不夸大：JPEG 无去背图时明确"不能本地合成"；OCR 未配置保持 `unknown`，不自动当通过。

### 关键断言

- 编译：`scene_1` 指令含 `暖白渐变`/`柔和侧光`/`下方留白 25%`/`45 度俯拍`/`天猫`/`10ml`/`静语薰衣草`/`#5A6B4A`/`最好`/`不得改变包装文字`，不含未确认的 `新疆`；`scene_2` 报 `FACT_NOT_CONFIRMED`。
- 哈希：同输入同哈希；改光线后哈希变化；同一任务全部交付物 `execution.content_hash` 相同而 `request_hash` 互不相同；事实变化（新增"新疆"为已确认）后执行计划哈希变化且新 prompt 含 `新疆`。
- 掩码：PNG → `border_color_keying` 且 `has_cutout=true`；JPEG 无矩形 → 422 `MASK_SOURCE_UNSUPPORTED_FORMAT`；越界矩形 → 422 `INVALID_SUBJECT_BOX`；合法矩形 → `manual_box` 且 `has_cutout=false`。
- OCR：未配置 `recognize` → `unknown`/`OCR_NOT_CONFIGURED`；候选全部 `confirmed:false`，置信 0.52 与 null 标 `needs_evidence`；关键文字 OCR 含 `静 语 薰 衣 草` 判 `pass`，`静语玫瑰` 判 `fail`。
- 排版层：SVG 含 `data:image/png;base64,`、`data-fact="容量"`、`>10ml<`、`font-family="方正兰亭黑"`、`data-source="brand_logo"`；`a<b&c` 被转义为 `a&lt;b&amp;c`。
- 安全：跨租户访问掩码预览按 404 处理；调整商品矩形前后原图 SHA-256 一致。

## 4. 设计决定

| 项 | 决定 | 理由 |
| --- | --- | --- |
| 文字渲染方式 | 供应商不绘制文字，统一走 SVG 图层 | 避免模型绘制精确文字出错，且图层可编辑 |
| JPEG 主体保护 | 卖家确认归一化矩形；无去背图时明确不可本地合成 | 不假装已实现主体保护 |
| OCR 阈值 | `OCR_THRESHOLD = 0.8`，低于阈值或缺失置信度需补证据 | 低置信信息不得自动确认 |
| OCR 验收口径 | 配置即 `contract_only` | 未经真实准确率评价，不称已通过真实验收 |
| 掩码存储 | 矩形只写元数据 | 不得改写卖家原始素材像素 |
